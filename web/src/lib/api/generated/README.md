# Generated API Client Types

> **DO NOT EDIT ANY FILES IN THIS DIRECTORY MANUALLY.**
>
> All files in `src/lib/api/generated/` are automatically produced by `openapi-typescript` from the committed OpenAPI specification (`docs/openapi.json`).
> Any manual edits will be overwritten on the next generation and will cause CI verification to fail.

## How to Regenerate

Whenever the backend OpenAPI document (`docs/openapi.json`) is updated:

```bash
cd web
npm run gen:api
```

Always commit both `docs/openapi.json` and the updated `web/src/lib/api/generated/` together in the same PR.
